Built a memory-safe, streaming PyTorch pipeline for top-quark jet tagging that trains directly from large HDF5 (pandas table) data without loading everything into RAM, mirroring real trigger-style constraints where fast, deployable models matter; includes a chunked HDF5 reader, robust auto label detection (single-label or two-column one-hot), leak-safe distributed holdout creation with exact row exclusion during training, feature scaling from a spread sample to avoid bias, an imbalance-aware GELU MLP (BatchNorm + Dropout) trained with `pos_weight`, AMP, AdamW, ReduceLROnPlateau, and early stopping, plus threshold tuning via Youden’s J and F1 for practical operating points, delivering leak-safe holdout performance around AUC 0.9997 with strong F1/accuracy at low thresholds on a ~1.211M-row training set.
